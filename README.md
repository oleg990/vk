# Бот VK «Олег Маханько | Недвижимость»

Бот группы [vk.ru/makhanko_nedvizhimost](https://vk.ru/makhanko_nedvizhimost). Go 1.24, без внешних зависимостей.

## Что умеет

| Пункт меню | Что делает | Куда идёт результат |
| --- | --- | --- |
| 🏠 Подобрать квартиру | Квиз: город, новостройка/вторичка, комнаты, бюджет, оплата, сроки, пожелания | Заявка **ПОКУПАТЕЛЬ** |
| 💰 Продать недвижимость | Квиз продавца + до 10 фото + вопрос «что после продажи» + предварительная оценка по цене м² | Заявка **ПРОДАВЕЦ** (метка «двойная сделка», если дальше новостройка) |
| 🧮 Рассчитать ипотеку | Стоимость, взнос, срок, программа или своя ставка → платёж, переплата, нужный доход | По кнопке «Хочу подбор» — заявка **ИПОТЕКА** |
| 📞 Связаться с Олегом | Вопрос + телефон | Заявка **ОБРАТНЫЙ ЗВОНОК** |

Перед телефоном бот всегда спрашивает согласие на обработку персональных данных. Без согласия заявка не сохраняется.
Заявки приходят Олегу личным сообщением от имени группы.

## Команды (только с аккаунта ADMIN_VK_ID)

```
/заявки [дней]          все заявки (по умолчанию за сутки)
/продавцы [дней]        продавцы (по умолчанию 30 дней)
/покупатели [дней]      покупатели
/ставки                 программы ипотеки
/ставка Семейная 6      добавить/изменить программу
/удалить_ставку Семейная
/цены                   цены за м² для оценки
/цена Юго-запад 120000  цена за м² по району или городу
/удалить_цену Юго-запад
/помощь
```

Пока ставки не заданы, калькулятор спрашивает ставку у клиента. Стартовая цена для оценки — 114 700 ₽/м² по Старому Осколу (средняя по прайсу на 01.10.2026); уточни её командами `/цена`.

## Запуск

Бот работает через Long Poll: сам ходит в VK, поэтому домен и HTTPS для него не нужны (они понадобятся для Mini App).

### 1. Подготовка в VK (уже сделано, кроме ключа)

- [x] Группа создана, сообщения и «Возможности ботов» включены, кнопка «Начать» добавлена
- [x] Long Poll API включён (версия 5.199), события: входящее сообщение, действие с сообщением, разрешение/запрет
- [ ] **Создать ключ доступа**: Управление → Работа с API → Ключи доступа → Создать ключ → права «Управление сообществом» + «Сообщения сообщества». Ключ — только в `.env` на сервере
- [ ] **Написать любое сообщение в группу со своего аккаунта** — иначе VK не даст боту присылать тебе заявки
- [ ] Узнать свой VK id (число) — для `ADMIN_VK_ID`

### 2. Сборка (на своём компьютере или на сервере)

```bash
GOOS=linux GOARCH=amd64 go build -o realty-bot ./cmd/bot
```

### 3. Сервер (Linux, systemd)

```bash
sudo useradd --system --home /opt/realty-bot realty-bot
sudo mkdir -p /opt/realty-bot/data
sudo cp realty-bot /opt/realty-bot/
sudo cp .env.example /opt/realty-bot/.env    # заполнить VK_TOKEN и ADMIN_VK_ID
sudo chown -R realty-bot:realty-bot /opt/realty-bot
sudo chmod 600 /opt/realty-bot/.env
sudo cp deploy/realty-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now realty-bot
journalctl -u realty-bot -f                  # логи
```

Обновление: собрать заново, заменить `/opt/realty-bot/realty-bot`, `sudo systemctl restart realty-bot`.

### Проверка

```bash
go vet ./... && go test ./...
```

## Устройство

```
cmd/bot            точка входа: настройки, Long Poll, передача сообщений боту
internal/vk        клиент VK API: Long Poll, messages.send, users.get, клавиатуры
internal/bot       меню, сценарии (flows.go), движок шагов (engine.go), команды (admin.go)
internal/mortgage  аннуитетный платёж
internal/storage   интерфейс хранилища + файловая реализация (JSON, атомарная запись)
```

Хранилище — один JSON-файл: хватает на старт. Для роста (Mini App, каталог новостроек Воронежа)
добавить реализацию `storage.Store` на PostgreSQL — код бота менять не нужно.
