# Бот VK «Олег Маханько | Недвижимость»

Бот группы [vk.ru/makhanko_nedvizhimost](https://vk.ru/makhanko_nedvizhimost). Go 1.24, без внешних зависимостей.

## Что умеет

| Пункт меню | Что делает | Куда идёт результат |
| --- | --- | --- |
| 🏠 Подобрать квартиру | Квиз: город, новостройка/вторичка, комнаты, бюджет, оплата, сроки, пожелания | Заявка **ПОКУПАТЕЛЬ** |
| 💰 Продать недвижимость | Квиз продавца + вопрос «что после продажи» + предварительная оценка по цене м² | Заявка **ПРОДАВЕЦ** (метка «двойная сделка», если дальше новостройка) |
| 💳 Консультация по ипотеке | Короткий вопрос (можно пропустить) → «📞 Позвонить Олегу» или оставить номер | Заявка **ИПОТЕКА (консультация)** |
| 📞 Связаться с Олегом | Вопрос + телефон | Заявка **ОБРАТНЫЙ ЗВОНОК** |

Перед телефоном бот всегда спрашивает согласие на обработку персональных данных. Без согласия заявка не сохраняется.
Заявки приходят Олегу личным сообщением от имени группы.

Ночью (00:00–09:00 по `TZ_NAME`) клиент один раз получает «Олег ответит с 9:00, пока можно пройти квиз». В каждый пост бот сам добавляет ссылку `vk.me/club<id>` «Написать мне» перед хэштегами.

## Команды (только с аккаунта ADMIN_VK_ID)

```
/статистика            заявки за сегодня, 7 и 30 дней по видам
/заявки [дней]          все заявки (по умолчанию за сутки)
/продавцы [дней]        продавцы (по умолчанию 30 дней)
/покупатели [дней]      покупатели
/ставки                 программы ипотеки
/ставка Семейная 6      добавить/изменить программу
/удалить_ставку Семейная
/цены                   цены за м² для оценки
/цена Юго-запад 120000  цена за м² по району или городу
/удалить_цену Юго-запад

```

Пока ставки не заданы, калькулятор спрашивает ставку у клиента. Стартовая цена для оценки — 114 700 ₽/м² по Старому Осколу (средняя по прайсу на 01.10.2026); уточни её командами `/цена`.

## Запуск

Бот работает через Long Poll: сам ходит в VK, поэтому домен и HTTPS для него не нужны (они понадобятся для Mini App).

### 1. Подготовка в VK (уже сделано, кроме ключа)

- [x] Группа создана, сообщения и «Возможности ботов» включены, кнопка «Начать» добавлена
- [x] Long Poll API включён (версия 5.199), события: входящее сообщение, действие с сообщением, разрешение/запрет
- [ ] **Создать ключ доступа**: Управление → Работа с API → Ключи доступа → Создать ключ → права «Управление сообществом» + «Сообщения сообщества». Ключ — только в `.env` на сервере
- [ ] **Написать любое сообщение в группу со своего аккаунта** — иначе VK не даст боту присылать тебе заявки
- [ ] Узнать свой VK id (число) — для `ADMIN_VK_ID`

### 2. Сборка (на своём компьютере или на сервере)

```bash
GOOS=linux GOARCH=amd64 go build -o realty-bot ./cmd/bot
```

### 3. Сервер (Linux, systemd)

```bash
sudo useradd --system --home /opt/realty-bot realty-bot
sudo mkdir -p /opt/realty-bot/data
sudo cp realty-bot /opt/realty-bot/
sudo cp .env.example /opt/realty-bot/.env    # заполнить VK_TOKEN и ADMIN_VK_ID
sudo chown -R realty-bot:realty-bot /opt/realty-bot
sudo chmod 600 /opt/realty-bot/.env
sudo cp deploy/realty-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now realty-bot
journalctl -u realty-bot -f                  # логи
```

Обновление: собрать заново, заменить `/opt/realty-bot/realty-bot`, `sudo systemctl restart realty-bot`.

### Проверка

```bash
go vet ./... && go test ./...
```

## Устройство

```
cmd/bot            точка входа: настройки, Long Poll, передача сообщений боту
internal/vk        клиент VK API: Long Poll, messages.send, users.get, клавиатуры
internal/bot       меню, сценарии (flows.go), движок шагов (engine.go), команды (admin.go)

```

Хранилище — один JSON-файл: хватает на старт. Для роста (Mini App, каталог новостроек Воронежа)
добавить реализацию `storage.Store` на PostgreSQL — код бота менять не нужно.

## Автопостинг

Работает на сервере без браузера: очередь постов лежит в репозитории, бот сам делает фото, присылает превью и публикует.

```
content/queue.json          ← посты: id, publish_at, text, prompt (английский запрос для FLUX), overlay
content/posts/<id>/overlay.png  ← плашка 1080×1350 (tools/overlay.py)
```

1. Новые посты добавляются в `content/queue.json` и пушатся в `main`.
2. Раз в 5 минут бот забирает очередь (`CONTENT_URL`), берёт фото: сначала бесплатные фотостоки по полю `query` — Pixabay (`PIXABAY_KEY`), Pexels (`PEXELS_KEY`), Openverse (без ключа, только CC0 и общественное достояние), затем генерация — Kandinsky (Fusion Brain, `FB_KEY` + `FB_SECRET`), запасной — FLUX.1-schnell через Hugging Face (`HF_TOKEN`); если генерация не удалась 3 раза — обложка на фирменном фоне с пометкой в превью, накладывает плашку и присылает Олегу превью с кнопками **✅ Опубликовать / 🔁 Другое фото / ❌ Отклонить**.
3. «✅ Опубликовать» — бот загружает фото на стену и создаёт пост от имени группы. Если до `publish_at` больше 10 минут — это отложенная запись VK, и VK публикует её сам в нужное время; если время прошло — сразу.
4. `/очередь` — статусы, `/обновить` — забрать очередь сейчас.
5. `/срочно Текст` — внеочередной пост прямо из VK: текст после команды, можно приложить фото (иначе — фирменный фон с плашкой `content/urgent_overlay.png`). В превью плановых постов есть «⚡ Сейчас» — опубликовать немедленно.
6. Карусель (до 10 слайдов): опишите пост в `content/posts/<id>/spec.json` (обложка `cover` с FLUX-промптом, слайды-списки `list`, финальный `cta`) и запустите `python3 tools/build_post.py content/posts/<id>/spec.json` — скрипт нарисует оверлеи и добавит пост в `content/queue.json` с полем `slides`.

Нужно в `.env`: `VK_USER_TOKEN` (пользовательский ключ администратора группы: wall, photos, offline) и ключ генератора (`FB_KEY`/`FB_SECRET` или `HF_TOKEN`). Без ключей пост с `prompt` ждёт; пост без `prompt` получит фирменный градиентный фон.

Добавить или заменить ключи на сервере: положить рядом с `install.sh` файл `env.add` со строками `KEY=VALUE` и запустить `install.sh` — он допишет их в `/opt/realty-bot/.env` и удалит `env.add`.

## Панель Олега и «сделай пост»

Админ (ADMIN_VK_ID) вместо клиентского меню видит панель: 📝 Сделай пост, ⚡ Срочный пост, 📋 Очередь постов, 🔄 Обновить, 📊 Статистика, 📥 Заявки за сутки, 💰 Продавцы, 🏠 Покупатели, 👀 Меню клиента, ❓ Помощь. Вернуться в панель — «меню».

«сделай пост [пожелание]» (или кнопка) запускает задачу Claude «Посты VK: сделай пост» через Routines API (`ROUTINE_ID`, `ROUTINE_TOKEN`): она берёт сайты из `content/sources.json`, собирает актуальные цены/сроки/акции, делает 3–5 постов (`tools/build_post.py`, разные стили) и пушит их в очередь. Бот присылает превью на одобрение. Повторный запуск — не чаще раза в 15 минут.

### Аналитика

Бот сам берёт цифры из VK API (`wall.get` — просмотры, лайки, комментарии, репосты по постам; `stats.get` — охват, посетители, подписки) и считает заявки из своей базы. Нужен `VK_USER_TOKEN` администратора с правами `wall`, `stats`, `offline`.

- Кнопка «📈 Аналитика» или `/аналитика` — разбор за 30 дней: лучшие и слабые посты, средние просмотры и реакции по темам, лучшее время, заявки за неделю.
- По понедельникам после 10:00 (`TZ_NAME`) тот же разбор приходит сам.
- При «сделай пост» бот добавляет к запуску задачи Claude блок `[СТАТИСТИКА]` — Claude выбирает темы и рубрики с учётом того, что заходит лучше. Если VK не отвечает, посты делаются как обычно.
- Тема поста определяется по ключевым словам и хэштегам; при менее чем 5 постах с просмотрами выводы помечены как предварительные.

### Запас постов

Посты с `"draft": true` в очереди — запас: бот их не трогает, пока Олег не нажмёт «сделай пост» без пожеланий. Тогда бот сразу выдаёт до 3 черновиков (даты — через день после последнего поста, 19:00), шлёт превью и, если в запасе осталось меньше 3, запускает задачу Claude пополнить запас. Инструкция задачи — `content/ROUTINE.md`.

### Режим «по запросу» (включён, `OnDemand`)

Расписания нет: все посты из `content/queue.json` (и с `publish_at`, и черновики) — запас.
- «📝 Сделай пост» — бот присылает 1 случайный пост из запаса; «✅ Опубликовать» — сразу на стену, «🔁 Другое фото» — тот же пост с новым фото, «❌ Отклонить» — убрать из запаса. Если в запасе меньше 3 новых постов — фоном запускается задача Claude (3 поста разных типов: новостройки/акции, новость рынка, полезная статья, рубрика).
- «сделай пост про …» — задача Claude делает посты по теме, бот сам показывает первый готовый.
- «📋 Очередь постов» — весь запас списком с номерами (по 9 на страницу); номер — прислать пост на одобрение. 👀 — уже присылался и ждёт решения.
